## Português (Brasil)

- Ativa o Discord Rich Presence no Desktop com o aplicativo oficial do Pad2PS Launcher: mostra quando você está navegando na biblioteca e, ao iniciar um jogo, exibe o título, o tempo de sessão e o controle conectado. O recurso funciona com segurança mesmo quando o Discord não está aberto.
- Adiciona a integração opcional com a IGDB para consultar sinopse, ano, gêneros, desenvolvedora e capturas de tela nos detalhes dos jogos.
- As credenciais da Twitch/IGDB são inseridas pelo usuário e ficam criptografadas no cofre seguro local do dispositivo. As consultas são feitas diretamente às APIs oficiais, sem servidor externo do Pad2PS.
- Metadados ficam em cache local para continuarem disponíveis offline; a integração pode ser ignorada sem afetar a biblioteca.

## English

- Enables Discord Rich Presence on Desktop with the official Pad2PS Launcher application: shows when you are browsing the library and, when a game starts, displays its title, session time, and connected controller. It safely handles cases where Discord is not open.
- Adds optional IGDB integration to show game summaries, release year, genres, developer, and screenshots in game details.
- Users provide their own Twitch/IGDB credentials, which are encrypted in the device's local secure vault. Requests go directly to the official APIs, with no Pad2PS external server.
- Metadata is cached locally for offline access; the integration can be left disconnected without affecting the library.
